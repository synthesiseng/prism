---
title: Prism
description: Native-first HTML-in-Canvas runtime for managed HTML/CSS canvas surfaces.
---

Prism is runtime infrastructure for apps that want real HTML/CSS elements to participate as managed canvas surfaces.

It builds on the HTML-in-Canvas proposal and related WICG work. The platform provides the underlying primitive; Prism provides the runtime layer around it.

Prism does not replace your renderer. It gives canvas applications managed DOM-authored surfaces.

## What Prism owns

- `CanvasRuntime`
- `CanvasSurface` registration
- backend selection
- paint lifecycle
- invalidation
- CSS-pixel surface bounds
- backing-store conversion helpers
- paint readiness
- export timing
- surface cleanup

## What your app owns

- app state
- data
- templates
- transforms
- animation loop
- layout decisions
- chart or rendering logic
- UI decisions
- interaction state

## Current scope

Prism v1 is 2D-first. WebGL/WebGPU and renderer integrations are future-facing, not the current public API center.

Installation and quickstart examples use published alpha.9. Alpha.10 candidate changes are marked in the relevant pages. See [Installation](/docs/tutorials/installation) for the published package and qualified native browser configuration. Native mode requires Canvas Draw Element; the flag alone does not establish compatibility. Chrome uses:

```txt
chrome://flags/#canvas-draw-element
```

Brave uses:

```txt
brave://flags/#canvas-draw-element
```

Fallback draws placeholders, not HTML snapshots. It exists only as a compatibility path and does not define the public API.
