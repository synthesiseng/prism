title: CanvasSurface
description: The public surface facade returned by registerSurface().
---

`CanvasSurface` is a facade returned by `registerSurface()`. Apps should not construct it.

```ts
const surface = runtime.registerSurface(element, {
  bounds: { x: 24, y: 32, width: 360, height: 220 }
});
```

## Surface API

- `element`
- `isDisposed`
- `getBounds()`
- `setBounds(bounds)`
- `dispose()`

Surface bounds describe the border box in CSS pixels. Prism writes `box-sizing: border-box`, width and height before painting. Padding and borders fit inside those bounds. Use `setBounds()` when layout changes; do not reach into backend or native implementation details.

Prism applies native sizing before the browser snapshot. A size change during `onPaint()` defers drawing until a fresh snapshot; `paintOnce()` waits for that pass. Function-based bounds are evaluated when drawn and can also defer a pass. Keep paint handlers repeatable: a retry runs them again, and earlier drawing in an incomplete pass is not rolled back.

```ts
surface.setBounds({ x: 48, y: 64, width: 420, height: 240 });
surface.dispose();
```

Disposing a surface unregisters it from the runtime and restores Prism-owned DOM state when it still matches Prism's last write. See [Cleanup](/docs/explanation/cleanup). Calling `dispose()` more than once is safe.

`runtime.destroy()` disposes every registered surface. After disposal, `isDisposed` is `true`; `getBounds()` and `setBounds()` throw.

Measure an auto-height inner wrapper when content determines the height. The outer surface's `offsetHeight` is the size Prism last assigned, so it cannot tell you that content has shrunk. See [Migrating from alpha.8 to alpha.10](/docs/how-to/migrate-alpha10).

Unchanged literal bounds do not request another paint. A position change after `drawSurface()` requests a following paint; it does not change the draw already performed.
